05 / STANDARD OPERATING PROCEDURE (SOP) SAMPLE

Process Documentation: Employee Lifecycle

"I keep systems running, keep assets accountable and document what I build so that others can run it after me."

STEP 01

Receive Request

HR or manager sends the new joiner's name, role, department and official start date.

STEP 02

Create Account

Create the Microsoft 365 user and mailbox; assign the licence; set the initial password to be changed at first sign-in.

STEP 03

Set Permissions

Add the user to the required security groups, shared mailboxes and departmental folders for their role.

STEP 04

Prepare Device

Install operating system updates, required software and anti-virus; join to the company setup; physically label the asset.

STEP 05

Record Asset

Enter the device serial, model, tag, issue date and assigned user in the central IT asset inventory.

STEP 06

Signed Handover

Hand over device and credentials; the employee signs the physical Device Receiving Acknowledgement form.

STEP 07 • FINAL VERIFICATION

Confirm & Close Request

Verify first sign-in, Outlook email flow, network printer mapping, and Wi-Fi/VPN access work seamlessly with the user; close the onboarding ticket.

REV 01 • ACCESS

Disable Access

Revoke M365/AD sign-in sessions, reset passwords, and convert mailbox to shared/forwarded per HR policy.

REV 02 • HARDWARE

Collect Device

Inspect returned laptop, charger, mouse, and ID/access cards against original issue sheet.

REV 03 • SIGN-OFF

Device Return Form

Complete and sign the formal Device Return Acknowledgement form for HR clearance.

REV 04 • LICENCE

Reclaim Licence

Remove or reassign Microsoft 365 & commercial software licences to prevent billing waste.

REV 05 • REGISTER

Update Inventory

Mark asset status as In-Stock / Ready for Re-provisioning in the master IT Asset Register.
